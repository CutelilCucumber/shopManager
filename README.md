D&D Market

A simple Dungeons & Dragons market interface that allows users to browse multiple themed shops, view item catalogs, and manage a shared shopping cart. Built as a React single-page application using React Router for navigation and lifted state for cart management.

Features

Multiple shop views with category-based inventories Dynamic routing for individual shops Shared cart across pages Modular component structure

Tech Stack

React React Router JavaScript CSS Modules

Running Locally 
npm install 
npm run dev
